Drop your articles here.

1. One Markdown file per story, e.g. my-story.md
2. First line is the headline:  # The Headline Goes Here
3. Optional dek (subhead) on the next line:  > The dek goes here
4. Optional byline, wrapped in asterisks:  *By Name, Ball Street Journal*
5. Then the body, paragraphs separated by a blank line.
6. Add the story to index.json:

   { "id": "my-story", "title": "The Headline Goes Here" }

The id must match the file name without .md.
The title in index.json is what visitors pick on the phone.
You can delete the sample stories once yours are in.
